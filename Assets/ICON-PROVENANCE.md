# Throughline app icon — 0.20.1

The current icon is original project artwork generated deterministically by `Assets/generate-icon.py`. It uses a warm-ivory **T** crossed by one copper line on a matte graphite housing. The line is the study connection running through the mark; the restrained geometry follows the app's physical, functional visual language. The PNG master, iconset and `.icns` are all generated from the same source. The icon was inspected at 1024 and 32 pixels. Pillow is needed only to regenerate the artwork, not to build or run the app.

The prior Lectern 0.17 icon was an **L** with a bookmark. It was generated on 2026-10-28 using the built-in image-generation tool. That historical artifact is retained in Git history; the public beta now uses the Throughline mark.
