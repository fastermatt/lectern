# Contributor roadmap

These are invitations, not claims that an issue is assigned or a feature is complete.
Create an issue to agree on scope and avoid duplicate work.

| Area | Small first contribution | Acceptance check |
|---|---|---|
| Installation | Test the beta on a second clean Apple Silicon Mac | Record chip, memory, OS, download-to-first-passage and optional model flow |
| Accessibility | Keyboard/VoiceOver review of one panel | Reproducible issue and before/after evidence; light/dark preserved |
| Localization | Inventory hard-coded strings in one view | Key plan, sample translation, no unreviewed bulk machine translation |
| Resource provenance | Add a pinned licensed input fetcher for one generator | Exact edition/URL/hash/notice; deterministic output; no hidden private files |
| Research | Review one catalogue entry or caution | Exact edition/passage, primary evidence, contrary reading, rights status |
| Testing | Replace one private-corpus audit with a synthetic behavior fixture | No copyrighted text copied; behavior still meaningfully verified |
| AI setup | Improve cancellation/retry feedback | No partial installation or dropped error; no account required |
| Documentation | Test README steps from a fresh clone | Commands work without the original developer's machine |

Larger proposals needing design first: signed/notarized releases and secure updates,
localization/RTL, deeper offline full-text search, broader licensed historical texts,
and a sustainable maintainer/editorial team. Do not promise Logos feature or corpus
parity. Do not reintroduce uncleared HCF excerpts to improve apparent coverage.

Current limits: Mac-only app; manual updates; no staffed review board; optional AI
accuracy is not doctrinal assurance; full regeneration of every imported corpus still
needs additional pinned inputs. A useful project can state these limits plainly.
