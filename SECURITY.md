# Security

Lectern is a beta. The current source and latest published beta are the initial
maintenance scope; no long-term support schedule or guaranteed response time is offered.

Do not post secrets, private notes, exploitable details or a working exploit publicly.
Once enabled, use this repository's **Security → Report a vulnerability** to contact
maintainers privately. If that option is absent, do not disclose the details in an
issue; ask for a private reporting channel without including the vulnerability.
Enabling private reporting and naming a responder are required publication setup steps.

Include the affected version, platform, reproduction steps and impact. Share the
minimum data needed; redact tokens and personal study material. Test against your own
installation, not other people's devices or accounts. Coordinated fixes should be
reviewed before public release. Security fixes must not introduce silent cloud fallback,
read users' notes without consent, or distribute publisher/model credentials.
