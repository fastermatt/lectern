Passage-guide reference data, generated by scripts/build-reference.py (workstream J, 0.8).
See scripts/reference-sources/SOURCES.md for provenance and Resources/Licenses/reference-*.txt
for licence evidence. Never hand-edit these files — rerun the build script instead.

  nave/verse-index/<BOOK>.json    "chapter:verse" -> [topic names], RANKED, <=12: topics that cite the
                                  verse directly (narrowest citing span <=10 verses, or named in the
                                  verse's own BSB text)                    (Nave's Topical Bible)
  nave/verse-index-more/<BOOK>.json  same shape: topics that reach the verse only through a wide
                                  citation (bare chapter, long run) or past the cap, ranked
  nave/topics/<A-Z>.json          topic name -> {refs, seeAlso, sections} (A-Z sharded, lazy)
  easton/verse-index/<BOOK>.json  "chapter:verse" -> [headwords], RANKED, <=8 (Easton's Bible Dictionary)
  easton/verse-index-more/<BOOK>.json  same shape: wide-citation / overflow headwords, ranked
  easton/articles/<A-Z>.json      headword -> {title, text}               (A-Z sharded, lazy)
  easton/book-intros.json         book code -> Easton headword for that book's introduction
  tipnr/verse-index/<BOOK>.json   "chapter:verse" -> [name IDs]           (STEPBible TIPNR)
  tipnr/names/<A-Z>.json          name ID -> {name, kind, description, refs} (A-Z sharded, lazy)
  meta.json                       attribution strings + source-file hashes for all three datasets

Read by ReferenceStore.swift; rendered by TopicsSection/DictionarySection/PeoplePlacesSection
in ReferenceSections.swift. Compare (CompareSection.swift) reads ScriptureLibrary/
OnlineTranslations directly and has no data files of its own here.
