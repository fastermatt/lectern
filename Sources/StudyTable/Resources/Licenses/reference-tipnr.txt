Thruline Bible — Reference licence record: STEPBible TIPNR (People & Places)
=============================================================================

Content: 4,242 disambiguated proper-name records (3,129 people, 1,011
places, 102 other proper nouns), each with a compact description and every
verse reference. Used to build `Resources/Reference/tipnr/**`.

Source: TIPNR — "Translators Individualised Proper Names with all
References", from the STEPBible-Data repository:
  https://github.com/STEPBible/STEPBible-Data
  file: "Proper Nouns/TIPNR - Translators Individualised Proper Names with
  all References - STEPBible.org CC BY.txt"
Cached at scripts/reference-sources/TIPNR.txt.

AI-drafted descriptions: the source file's own header states "Every
individual has a description in brief, short and article length (created
by Claude 3 AI)" — these description tiers (`@Briefest=`/`@Brief=`/
`@Short=`/`@Article=`) are STEPBible's own published content, released
under the same CC BY 4.0 as the rest of the file. This build uses the
`@Short=` tier (falling back to `@Brief=`/`@Briefest=` when empty) as the
People & Places card's description — attributed to STEPBible like
everything else from this file, never presented as Thruline's or
Claude's own writing.

Documented, bounded enrichment: TIPNR's own reference tagging follows its
base text (mainly the ESV, per its header: "Proper Nouns in the ESV (+
differences in KJV & NIV)"); `scripts/build-reference.py`'s
`enrich_same_chapter_name_matches` adds a verse to a name's reference list
only when (a) TIPNR already ties that specific individual/place to that
exact chapter via a confirmed occurrence elsewhere in it, and (b) one of
TIPNR's own recorded name spellings for that individual appears as a whole
word in the app's own bundled BSB text of the otherwise-untagged verse —
e.g. Acts 9:3 (BSB: "As Saul drew near to Damascus...") vs the ESV's "Now as
he went on his way...". 7,619 such additions in the 2026-09-23 build,
reported by the build script.

Excluded: the "EXCLUDED OTHER" category (STEPBible's own label, e.g. the
language name "Latin") is dropped entirely, per the source's own guidance.
